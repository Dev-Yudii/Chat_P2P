Instruções de Inicialização do Projeto P2P Chat

1. Crie o seu ambiente virtual Python:
   python -m venv venv

2. Ative o ambiente virtual no terminal (Windows PowerShell):
   (Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned) ; (& .\venv\Scripts\Activate.ps1)

3. Instale as dependências requeridas pelo projeto:
   pip install -r requirements.txt

4. Execute a aplicação especificando a porta TCP e o seu nome/apelido:
   python app.py 5001 --name "SeuNome"

Dica para testes locais: Abra outros terminais, ative o venv e use portas diferentes:
   python app.py 5002 --name "Pessoa1"
   python app.py 5003 --name "Pessoa2"
